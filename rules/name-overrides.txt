# 逐文件的取名覆盖。一行一条：`<现在的文件名（不带后缀）> = <想要的歌名> [| <想要的作者>]`
# # 开头是注释。不写 `| 作者` 就只改歌名，作者仍按常规规则（文件名优先）取。
#
# 用途：常规规则是"歌名以标签为准、作者以文件名为准"，遇到标签本身不合意、
# 又不想去动音频文件的时候，写在这里由脚本统一处理 —— tags 会把结果写进标签，
# rename 随之改名，两边永远一致。
#
# 为什么键是**文件名**而不是歌名：库里有两首歌都叫 `Odyssey`
# （`Odyssey - Dysphorid` 和 `Odyssey - P-Music`），按歌名做键会一次改中两个、撞名。
#
# 生效一次之后键就不匹配了（文件名已经变了），条目自然失效，不会反复重写。
# 想再改一次，把左边改成**现在的**文件名即可（看 rename 报告或直接 ls）。

# 标签歌名前多了 BONUS（原文件名就叫 Federation）
BONUS Federation - Ben Prunty = Federation

# 标签歌名只有 Odyssey，原名里的 D-music 是它的专辑名，这里当作者用
Odyssey - Dysphorid = Odyssey | D-music
